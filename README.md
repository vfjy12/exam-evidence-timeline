# 考公证据时间轴 0.1.0

独立插件，不替换知识中枢、词典或原多维表格。用于保存事件原始时间表达、年/月/日/未知精度、区间、来源文件、定位依据与争议。创作、发明、最早记载、传播分开记录，专题共用现有实体 MD 链接，不复制实体。

打开命令“打开证据时间轴”，新增事件后存到“证据时间轴”目录。点击标题打开 Markdown 编辑，现阶段来源路径和实体路径手工输入。公元前年份负数，无公元 0 年；古代月日历法换算未实现，原始表达保留，排序按输入的规范时间，不自动推断。不精确时间在列表中保留精度标记。

安装：解压 exam-evidence-timeline 到库 .obsidian/plugins/，重启并启用“考公证据时间轴”。没有 data.json，不修改其他插件。

此版本是日期排序列表，尚未实现可缩放图形时间轴、图谱联动、PDF 稳定页码跳转、年代/世纪/约数范围推理和批量导入，不代表全部系统设计完成。语法和时间逻辑模拟测试通过；Obsidian/iPad 实机未验证。先在探索库使用。
